# Fishing Dashboard — Visual Redesign v11.0.0

Όλες οι εγκεκριμένες οπτικές αλλαγές (W1–W11) σε ένα πακέτο.

## Αρχεία
- index.html
- style.css (με VISUAL v11 block στο τέλος)
- app.js
- manifest.json
- service-worker.js (CACHE v11.0.0)
- PNG assets (moon, techniques, fish, sun, score, rod)

## Τι αλλάζει (εγκεκριμένα)
W1  Καιρός ανά ώρα — sky-style κελιά, compact
W2  Άνεμος — αρχικά βελάκια (χωρίς αλλαγή στυλ)
W3  Ρεύματα — αρχικά βελάκια
W4  Πίεση — κίτρινο νέον + fill + σκαμπανεβάσματα + πράσινο/μπλε/κόκκινο trend
W5  Σελήνη — χρυσαφί κείμενα + μπλε icon τίτλου
W6  Παλίρροιες — μπλε νέον + fill + trend χρώματα
W7  Καλύτερες ώρες — χρυσαφί σελήνης
W8  Fishing Score — polish gauge/stars
W9  Fish Activity — καθαρό fill panel / λίστα
W10 Alerts — cyan icons, χωρίς άσπρες τελείες
W11 Τεχνικές — object-fit εικόνων, χωρίς ξεμείναντα

## Deploy
1. Ανέβασε ΟΛΑ τα αρχεία στη ρίζα του GitHub repo (main)
2. Netlify θα κάνει auto-deploy από main
3. Hard refresh / private tab (cache v11.0.0)
