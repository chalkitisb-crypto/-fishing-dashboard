Fishing Dashboard — NEW v12.0.0
Καθαρή νέα εφαρμογή από την αρχή με όλα τα εγκεκριμένα W1–W11.

Widgets:
- Hero (ημερομηνία + ήλιος + metrics)
- Καιρός ανά ώρα (sky cells)
- Άνεμος (χρωματιστά βελάκια)
- Πίεση (κίτρινο νέον + σκαμπανεβάσματα + trend)
- Σελήνη (χρυσαφί κείμενα, μπλε icon, ↑↓)
- Ρεύματα
- Θάλασσα
- Παλίρροιες (μπλε νέον)
- Καλύτερες ώρες (χρυσαφί γραμμή)
- Fishing Score (gauge + καλάμι-δείκτης + αστέρια)
- Fish Activity (ψάρι + μπάρα + λίστα χωρίς overlap)
- Alerts (AI + cyan icons)
- Τεχνικές (κάρτες με fit εικόνων)

Deploy:
1. Σβήσε παλιά αρχεία από GitHub root (προαιρετικά αλλά καθαρότερα)
2. Ανέβασε ΟΛΑ τα αρχεία αυτού του φακέλου στη ρίζα main
3. Netlify auto-deploy
4. Άνοιξε σε ιδιωτική περιήγηση
